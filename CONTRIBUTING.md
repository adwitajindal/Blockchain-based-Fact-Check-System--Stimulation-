# Contributing to Proof of Truth

Thanks for your interest in improving this project! As this is a learning/portfolio project, I'm especially open to feedback and suggestions.

## How to Contribute

### Reporting Issues
Found a bug or have a suggestion? I'd love to hear about it!

**Email:** adwita.jindal.42@gmail.com

Please include:
- Description of the issue or suggestion
- Steps to reproduce (for bugs)
- Your environment (browser, OS)
- Screenshots if applicable

### Suggesting Features
Have ideas for improvements? Send me an email with:
- What feature you'd like to see
- Why it would be useful
- Any examples or references

### Code Contributions
If you'd like to contribute code:
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a pull request

### What I'm Looking For

**Especially interested in feedback on:**
- Security vulnerabilities or game theory exploits
- Better implementation approaches
- Code quality and structure improvements
- UI/UX enhancements
- Documentation clarity
- Smart contract architecture suggestions (for future phases)

**Areas that need work:**
- Preventing collusion and Sybil attacks
- Improving the voting mechanism
- Better mobile responsiveness
- Performance optimizations
- Test coverage

## Development Setup

```bash
# Clone the repo
git clone <your-fork-url>

# Install dependencies
pnpm install

# Start dev server
pnpm run dev

# Run linting
pnpm run lint

# Type check
pnpm run type-check
```

## Code Style

- Use TypeScript for all new code
- Follow existing code patterns
- Add comments for complex logic
- Keep functions small and focused
- Run `pnpm run lint` before committing
